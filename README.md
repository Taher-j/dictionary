# Dictionary (working title)

Offline-first Android and iOS app for saving vocabulary into personal dictionaries and reviewing it
with spaced repetition. No backend, no accounts, no network code.

## Setup

Requirements: Node 24+, pnpm, Android SDK (and Xcode on a Mac for iOS).

```bash
pnpm install
pnpm android      # build the development build and run it on a device or emulator
pnpm start        # start Metro for an already installed development build
```

This project uses development builds, not Expo Go. `android/` and `ios/` are generated by
`expo prebuild` and are not committed.

## Checks

```bash
pnpm check       # lint + typecheck + tests; must pass before anything is "done"
pnpm format      # apply Prettier and ESLint fixes
```

Typed routes come from `.expo/types`, which `pnpm start` (or `pnpm android`) generates. After
adding or renaming a route, start Metro once before `pnpm typecheck`.

## Database

Schema: `src/data/db/schema.ts`. After changing it, run `pnpm db:generate --name <change>` and
commit the new migration. Never edit a committed migration. Development builds have Settings →
Developer tools to seed 50,000 words and time list and search queries.

## Docs

Start with `CLAUDE.md` and `docs/PROGRESS.md`. The specification lives in `docs/`.

App name, bundle id and URL scheme are placeholders, defined once in `app.config.ts`
(see `docs/08-decisions.md`). App icon and splash image are still the Expo template's.
