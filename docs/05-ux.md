# UX

Guiding rule: the most common action on each screen takes one tap.

## Navigation

- Bottom tabs: **Today**, **Library**, **[+]**, **Stats**, **Settings**.
- The centre **[+]** is a button in the tab bar (not a floating button) and opens quick add from
  any tab.
- There is no Practice tab. Today is the practice entry; free practice starts from a dictionary or tag.
- Stacks: Library -> Dictionary -> Word. Edit and quick add are modals.
- The review session is full screen with no tab bar.
- Deep links: `/add`, `/word/[id]`, `/dictionary/[id]`, `/review`.
- Stats is a placeholder until Milestone 8.

## Screens

### First launch

No carousel, no account screen. One sheet: dictionary name plus term language and meaning
language (only the name is required). After creating it, open quick add with the keyboard up.
"Import a file" (from M6) and "Restore a backup" (from M5) are text links below.

### Today

Top to bottom:

```text
Today

+----------------------------------+
|  12 to review  -  about 4 min    |
|  9 due, 3 new                    |
|  [         Start review        ] |
+----------------------------------+

6 words need a meaning            >      (only when > 0; opens the Inbox)

Recently added
meticulous         English        >
die Gelassenheit   German         >
idempotent         Programming    >

Practice                                  (V1)
Weak words (14)                   >
```

- Nothing due: "All caught up" plus when the next review arrives.
- Backup reminder banner appears here when due (M5).
- No greeting, no dictionary list, no Import shortcut on this screen.

### Library

- Search field at the top; searches all dictionaries; results appear while typing, grouped by
  dictionary.
- Below: the dictionary list (emoji, name, word count, due count), reorderable in a "Reorder" mode
  with up/down buttons (screen-reader friendly, no drag library).
- Filter chips under the search field: dictionary, tag, status, starred, incomplete.
- With filters set and no search text, the matching words replace the dictionary list, grouped
  by dictionary. Search results are grouped by dictionary too.

### Dictionary

- Word list (FlashList), sort by A-Z or recently added.
- Header menu: rename, languages, "include in daily review", delete.
- Row: term, meaning (one line), a small status dot with an accessible label.

### Quick add (`/add`)

1. Term field focused, keyboard open.
2. Dictionaries as a row of chips; last used is preselected.
3. Meaning: one optional field below the term. "More fields" expands the rest.
4. Paste button inside the term field.
5. Inline duplicate warning while typing (debounced), with a link to the existing word.
6. "Save" closes. "Save and add another" keeps the keyboard up.
7. After saving: light haptic and a toast offering "Add details".

Accepts `term` and `context` query parameters (deep link, share). `context` (the sentence where the
word was found) prefills the Example field, shown expanded. It never saves on its own.

### Word detail

```text
< German                      star  ...

die Gelassenheit            [speak]        (speak: V1)
noun - die, no plural

serenity, composure

"Sie reagierte mit großer Gelassenheit."

[B2] [literature]            + tag

Look up in Wiktionary >                    (V1)

--------------------------------------
Young - next review in 3 days
Reviewed 7 times, 1 lapse           >

Source: Der Zauberberg
Added 12 Sep 2026
```

- The meaning sits directly under the term in large type.
- Tap a field to edit it in place. Empty optional fields hide behind one "Add details" row.
- Overflow menu: Suspend, Move to dictionary, Reset progress, Delete.
- The scheduling line opens the word's review history.
- There is no "Practice this word" button.

### Review session

- Card shows the prompt. Tap anywhere to reveal the answer.
- Four rating buttons at the bottom, each with a word and an interval ("Good · 3 d").
- Thin progress bar and a remaining count. No timer.
- Header: close, undo, "Edit this card".
- Light haptic on each rating.
- Card flip animation; with reduced motion enabled, a crossfade.

### Session summary

Cards reviewed, share rated Good or Easy, list of missed words with meanings (tap to edit),
count due tomorrow. "Done" is the primary button. "Keep going" appears only when more cards wait.

### Settings

Daily new-word limit, session size, theme, haptics on/off, tags management, backup and restore,
snapshots, trash, about.

Appearance: Theme (System, Light, Dark) and Language (System, English, Deutsch). Arabic is not in
the list; with Language set to System it is used when the device or per-app language is Arabic.
Switching to or from Arabic changes the layout direction, which needs a restart; the app says so.

Tags management lists every tag with its word count: rename, merge into another tag, delete
(asks first; the words keep everything else). Renaming to a name that already exists offers a merge.

## Accessibility (built into `src/ui`, not added later)

- Text follows the system font scale up to 200%. Layouts scroll rather than truncate.
- Touch targets at least 44 pt (iOS) / 48 dp (Android).
- Every interactive element has an accessibility label and role.
- Never colour alone: status and ratings always carry text.
- Review card for screen readers: reads the prompt, hint "double tap to reveal", then moves focus
  to the answer. Rating buttons read "Good, next review in 3 days".
- Reduced motion is respected everywhere.
- Colour tokens meet 4.5:1 contrast in light and dark themes.

## Theming

- Colour, spacing, radius and type tokens in `src/ui/tokens.ts`. Components never use raw hex values.
- Light and dark themes from the first screen; follows the system setting by default.

## Internationalisation

- Strings in `src/i18n/locales/en.json`, `de.json` and `ar.json`, accessed with `t()`. A test
  checks that every language has every key, its plural forms and the same placeholders.
- Interpolation and plural forms, never string concatenation.
- `Intl` for dates, relative times and numbers.
- Logical style properties so the layout mirrors in Arabic (right to left). Leave `textAlign`
  unset or `auto`/`center`; `left`/`right` do not flip.
- A dictionary's term and meaning languages are content metadata, independent of the UI language.
